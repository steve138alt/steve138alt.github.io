隐私政策

Privacy Policy · 生效及更新日期：2026-11-17

本政策适用于 PerfectDrop iPhone 游戏及其开发者网站。运营者是 PerfectDrop 独立开发者（GitHub：steve138alt）。联系邮箱：onelinesupport@gmail.com，请在主题中注明 PerfectDrop。

摘要：无需账号；分数和设置主要保存在设备本地。游戏提供可选 AdMob 激励视频。广告及隐私同意服务会处理部分设备、网络、广告互动与诊断信息，因此本产品不能被描述为“完全不收集数据”。网站没有自行加入广告、统计工具或追踪 Cookie。

1. 我们处理哪些信息

来源信息与目的
游戏本身最高分、音效/音乐/触感偏好保存在设备本地，用于游戏功能；当前局的塔、连击和续命资格在内存中处理。没有账号或开发者运营的云端分数库。
Google AdMob 与 UMP可能处理 IP 地址及其推断的大致地区、设备或应用相关标识符、系统与设备信息、广告曝光/观看/点击记录、产品互动、性能数据和崩溃诊断，用于广告投放、奖励确认、频次控制、衡量、故障排查和防欺诈。具体处理依地区、同意选择和 SDK 行为而异。
支持联系你主动发送的邮箱、消息及可选诊断资料，用于处理支持或隐私请求。请勿发送密码、支付资料或不必要的敏感信息。
网站托管GitHub Pages 作为托管方，可能接收 IP 地址、请求日志、浏览器信息等以提供和保护网站，遵循其隐私声明。

2. 广告与隐私选择

当前版本只提供主动选择的激励视频，不在游戏过程中强制弹出插屏或展示横幅。我们配置非个性化广告处理，关闭 Google 发布商第一方 ID，并且不请求 Apple ATT 跟踪授权。非个性化不等于零数据处理；广告仍可能使用网络或设备信息进行安全、频次控制和衡量。

应用启动时通过 Google User Messaging Platform 更新同意状态；如你所在地区需要，会展示隐私同意表单。仅在该平台允许请求广告时才初始化广告服务并加载广告。法律要求提供隐私选项时，可在应用“设置 → Ad privacy choices”重新选择。拒绝或改变选择不影响核心游戏；某些选择可能令视频不可用。观看广告是获取当次奖励的主动选择，不是同意所有追踪。

3. 第三方服务

  • Google Mobile Ads / AdMob：广告及奖励回调；Google UMP：地区性隐私消息和同意管理。
  • GitHub Pages：本网站托管。游戏核心不向 GitHub 上传分数或设置。
  • 邮箱服务：仅在你主动发邮件时处理该通信。

请参阅 Google 隐私政策、Google 在合作伙伴网站和应用中的数据使用、Google 移动广告 SDK 数据披露及 GitHub 隐私声明。这些服务的数据可能在你所在国家/地区以外处理。

4. 处理依据及保存期限

必要的本地状态用于提供游戏。需要同意的广告或存储处理依据适用法律取得同意；安全、技术服务和支持请求在适用时依据提供服务或合法利益处理，不替代法律要求的同意。我们不会出售由我们直接持有的个人信息。Google 对其广告服务数据的处理及当地法律下的出售/共享或定向广告选择，由其隐私表单和政策进一步说明。

本地纪录和偏好保留到你删除应用或系统清除相应数据；系统备份与恢复可能保留或恢复它们。当前对局在结束或关闭应用后不保证保留。支持邮件按解决请求及必要的法律、安全用途保存。第三方广告数据的保存由相关服务政策决定，开发者无法承诺直接删除其全部数据。

5. 你的权利

视适用法律，你可能拥有访问、更正、删除、限制或反对处理、撤回同意、获取副本及投诉的权利。可通过应用的广告隐私选项、系统隐私设置或联系邮箱提出请求。没有开发者账号或云端分数库，因此我们通常无法识别或导出你设备上的游戏数据。涉及 Google 或 GitHub 的数据也可向相应服务方提出请求。我们可能核实请求身份，但不会要求你提供不必要的资料。

6. 儿童与安全

本游戏面向一般受众，不专门面向未满 13 岁或当地法定儿童年龄的儿童。我们不会有意收集儿童的个人信息。如果你认为儿童向我们提供了个人信息，请联系开发者处理。若未来面向儿童或已知未成年用户提供广告，将先调整年龄处理和广告配置。

我们采用适当保护措施，但任何设备、网络或邮件系统都无法保证绝对安全。请勿在支持邮件中发送敏感信息。

7. 更新及联系

重大变化会通过更新本政策及必要的应用提示说明。当前公开版本可通过应用设置随时访问。
